# DiscoveryOSX v1.2.2-exp.8（实验包）

**这一版只做一件事：帖子正文页不再响应「向左滑」的返回手势。** 右滑返回保留，其它页面与功能一律不动。

## 1. 为什么去掉左滑

正文页的返回手势原本是**双向**的：右滑退出（页面跟着手指往右走），左滑也退出（页面往左滑走并淡出）。左滑在正文里本来另有用处——横向翻看图、拖动选区、横向甩动表格或链接行；它一旦同时被当成「返回」，手指稍微一横就把正在读的帖子关掉了，而且页面往左滑走的观感也和「返回」不一致（返回应该往右，回到它进来的那一侧）。

因此：**正文页只保留右滑返回**，左滑不再退出，页面也不会跟着左滑移动。

## 2. 改法：把手势限制成单向，而不是「滑完再判断」

不是在抬手时加个条件（那样页面仍然会跟着手指左移，松手再弹回来，观感像被取消了），而是在**手势识别层**就只认一个方向：

- 正文页的拖拽手势加了 `direction: "right"`（`panActivation`）。原生手势跟踪器（`Mounter.java panActivation` → `PanActivation::direction`）在手指移动过程中判定：往右超过 18pt 才让它激活；**往左移动直接把这条手势判负**，激活都不会发生。
- 于是左滑时页面不位移、不淡出、不会关帖子，正文的滚动、选区、横向翻看都不受影响（手势判负后触摸交还给周围的滚动视图）。
- 抬手逻辑里原先「左滑也退出」的那条分支随之删除，退出动画只剩右滑一个方向（`settleExit(…, 1)`），返回按钮的行为不变。
- 右滑返回的阈值（60pt 或 700pt/s）、`failOffsetY: 10`（上下滑动仍然交给列表滚动）一字未改。

## 3. 覆盖面

正文页只有一个组件（`src/ui/Thread.tsx` 的 `Thread`）在渲染，论坛首页、我的主题、收藏、我的回复、历史、搜索结果、版块内列表、以及从链接跳进来的帖子，走的都是它。所以这一处在组件内部生效，就等于**所有进入正文的路径**都生效，无需分别处理，也不存在某条入口漏改。

## 4. 修改范围（只动正文页手势）

- `src/ui/Thread.tsx`：`panActivation` 增加 `direction: "right"`；`onSwipeEnd` 删掉左滑退出分支；`leave()` 去掉不再需要的方向参数（恒为向右）；相关注释同步更新。
- **零改动**：私信会话页（`Conversation.tsx`，双向滑动返回保持原样）、首屏两列的左滑折叠、竖屏浮层（列表/版块）的右滑阶梯返回、查看器手势、正文选字、图片加载与预热策略、运行时（沿用 exp.5 起的 589a60f 自编译版本）。

## 5. 验证要点

1. 正文页**左滑**：帖子不关闭、页面不位移；正文仍可正常上下滚动，图片/链接不受影响；
2. 正文页**右滑**（超过 60pt 或轻快一甩）：照旧返回上一级，退出动画与之前一致；
3. 竖屏从列表进入正文后右滑返回 → 回到列表；横屏并排时右滑返回 → 回到无选中状态（与上一版一致）；
4. 从「我的主题 / 收藏 / 我的回复 / 历史」进入的正文，行为与论坛首页进入的完全一致；
5. 私信会话页左滑/右滑返回**仍然可用**（这里没有改）；
6. 首屏左滑折叠板块栏、竖屏浮层右滑回上一级，均不受影响；
7. 长按正文选字、图片查看器（左右切图 / 下滑关闭 / 双指缩放）不受影响。
