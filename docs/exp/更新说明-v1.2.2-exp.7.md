# DiscoveryOSX v1.2.2-exp.7（实验包）

**这一版修复查看器的左右切换与下滑关闭，并让相邻图片提前读好，切换不再等网络。**

## 1. 根因：手势被「可滚动的那一层」抢走了

查看器的拖拽手势（左右切换、下滑关闭）挂在图片容器上，而这个容器**在缩放用的 `Scroll` 里面**。它的尺寸原先是 `win.height - 8`，而 `Scroll` 的视口比它矮（上面还有名称条），于是：

1. 内容比视口高 → 这一层 `Scroll` 认为自己可滚动，手指一按就 `requestDisallowInterceptTouchEvent(true)`；
2. 手指一动，滚动层开始拖动 → 运行时的 `ScrollBox` 在滚动开始时调用 `mounter.cancelTouches()`（「原生滚动接管了触摸」），JS 的手势被**取消**；
3. 手势的结束回调拿到的 `cancelled = true`，左右切换与下滑关闭的判断全部不成立 → 表现为「滑了没反应」。

双指缩放是滚动层自己处理的，点击与长按走的是 press 通路，所以那两个还正常——与实测现象一致。

## 2. 修法：手势层挪到 `Scroll` 外面，缩放层保持不动

- 拖拽手势（`pan` + `panActivation`）从图片容器移到**包住 `Scroll` 的那一层**：它不再位于滚动内容里，滚动层抢不到它；
- `Scroll` 里只放图片本身（`availW × availH`）。1 倍时内容比视口小，**没有可滚动的余量**，滚动层不会认领触摸，也就不会取消手势；
- 双指缩放照旧（1×–4×）；放大后画面由滚动层平移，符合看图习惯；
- 左右切换/下滑关闭的阈值、动画、方向判断一字未改；点击空白关闭、长按菜单、保存/分享/扫码全部保持原样。

## 3. 加载与切换速度

- **相邻图片提前读**：看某一张时，把前一张、后两张的字节预读进同一份缓存，切换时直接命中，不再等网络。
- 原来用「三个 1×1 的隐藏图片」预热：每个都要建视图、布局、解码一次，却只留下 1×1 的位图。现在改成直接预热字节（`warmImages`），**少三个视图、少三次解码**，滑动与切换更顺。
- 正文侧沿用之前的策略（下载池 6 路、进帖预热 12 张、列表预取 8 张、本页优先），清晰度与请求尺寸都没动。

## 4. 修改范围

- `src/ui/imageViewer.tsx`：手势层与 `Scroll` 的嵌套关系调整；新增相邻图片预热 `effect`；去掉三个隐藏预热视图。
- 其它文件零改动；上一版（exp.6）的「选字在正文上完成」保持不动。

## 5. 验证要点

1. 查看器内**左右滑动**能切上一张/下一张，滑动手感与切图动画正常；
2. **向下拖动**超过约 90pt 能关闭查看器，短拖不会误关；
3. 双指仍能放大到 4×，放大后单指可平移画面；
4. 点击画面空白、底部「关闭」按钮仍能退出；长按仍出菜单（原图 / 保存 / 扫码）；
5. 连续左右切换时，下一张应基本立即出现（不再先黑一下再加载）；
6. 正文图片的显示速度、清晰度与楼层高度不变。
