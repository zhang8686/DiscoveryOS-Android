# DiscoveryOSX v1.2.0 更新说明

发布时间：2026-11-23

上一版（v1.1.9）为了「复制后自动收尾」换掉了原生输入框，结果是选区只能整行整段，任意位置选字没了。这一版把任意选字改回来，同时保住了「点复制就自动恢复正文」。

## 一、任意位置选字回来了

选字重新用原生输入框（只读、可选中）承载正文，也就是你熟悉的那一套：

- 长按正文 → 长按选中某个词 → 拖两端手柄**逐字**增减，句中、行间任意位置都能选。
- 不再出现「一点就是整行」的情况。

正文高度仍由排版文本决定，长按后文字下方不会再留出大片空白。

## 二、点浮条的「复制」，正文自动恢复

不用双击、不用点空白、应用里也没有任何自制按钮：

- 在系统浮条上点「复制」→ 文字进剪贴板 → **选区收起，正文立刻恢复**。
- 之所以能做到，是因为系统在复制结束后会把选区收成光标，这个变化框架会报给应用，于是正文就在那一刻回来。信号来自系统本身，不靠猜、不靠额外手势。

## 三、修掉「双击后整页点不动」

- **双击退出彻底删除**，不再有任何"在文字上点两下"的处理。
- 退出选字的每一步（收起选区、交还焦点、撤走输入框）都排到触摸事件分发结束之后执行：系统正在收它自己的选字工具栏时，不去动视图树。之前页面变"聋"，就是因为这个动作撞在了系统的收尾过程中。
- 选字状态下按返回键，先结束选字，不会把系统选区（和它的浮条）带到列表页。

## 四、手柄与选中底纹是系统蓝

选中底纹和两端手柄都用 Android 系统选区那个蓝（`#4285F4`），与其他应用选字时的观感一致。

## 五、保持不变

- 点正文以外的地方、或按返回键，同样可以退出选字。
- 附件图片在正文内显示、文件类附件按真实文件名下载、图片查看器的保存与分享，与前几版一致。

## 安装说明

- 包名 `com.Android.DiscoveryOSX`，版本 1.2.0（versionCode 59）。
- 签名与 v1.1.6 – v1.1.9 相同，**可直接覆盖升级**。
- v1.1.0 用的是另一份证书，需先卸载再安装。
