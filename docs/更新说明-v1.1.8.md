# DiscoveryOSX v1.1.8 更新说明

发布时间：2026-11-23

这一版只做一件事：把「选完字怎么退出」改对。

## 一、修复：双击结束选字后，整个界面点不动

上一版（v1.1.7）试图在双击时先收起选区、再撤走输入框，但没有解决——原因不在先后顺序，而在于**这些动作发生在了触摸事件自己的分发过程里**。

双击的第二下抬起时，如果在事件的回调里同步去改系统输入框的选区、再把输入框从界面上撤走，系统那一侧的选区状态会停在半途：手势结束了，页面却收不到之后的触摸，按钮和帖子都点不动，只能重启应用。

这一版的做法：

- **不再用双击退出**，双击这个手势彻底从选字流程里去掉。
- 所有退出动作（收起选区、交还焦点、撤走输入框）都排到**触摸事件分发结束之后**再执行，分两步收尾，中间留出时间让系统自己的选区界面先关掉。
- 三条退出路径（复制按钮、点正文以外的地方、返回键）走同一段逻辑，重复触发只生效一次。

## 二、改为「复制后自动退出」

选字时正文下方的提示行右侧新增一个「复制」按钮：

- 点它 → 把选中的文字放进剪贴板 → **立即恢复正文**，不需要再双击、点空白处，也不用找「完成」。
- 复制完会有「已复制选中文字」的提示。
- 若还没选中任何文字就点了「复制」，只提示「请先用长按选好要复制的文字」，不会把选字关掉——误触不会丢掉已经打开的选字状态。

## 三、保持不变的

- 长按正文进入选字，再长按选中一个词，拖两端手柄可以逐字增减选区。
- 系统自带浮条（复制 / 全选）仍在，用它的「复制」也可以；要退出时点提示行的「复制」或正文以外的地方。
- 附件图片在正文内显示、文件类附件按真实文件名下载、图片查看器的保存与分享，均与 v1.1.6 / v1.1.7 一致。

## 安装说明

- 包名 `com.Android.DiscoveryOSX`，版本 1.1.8（versionCode 57）。
- 签名与 v1.1.6、v1.1.7 相同，**已装这两个版本可直接覆盖升级**。
- 更早的 v1.1.0 用的是另一份证书，需先卸载再安装。
