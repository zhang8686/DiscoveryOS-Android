# DiscoveryOSX v1.2.2-exp（实验包）

这一版只为一件事存在：验证两处还没法在正式版里确认的改动。**它替换了框架运行时本身**（`libnsh.so` 与 `classes.dex` 都由本机从 nsh 0.6.0 源码重新编译），所以请把它当作实验包，不要当作日常版本。

## 1. 输入框的行距与正文一致

选字时正文变成原生输入框，之前的行距只能取字体自带的（比正文紧一点），框架没有开关可调。这一版给运行时补了一个「按格子填行距」的步骤：只读、可选择的输入框拿到的高度是正文算出来的高度，运行时把行距平分到这个高度上，于是每一行都落在正文原来的位置。

- 试验点：长按正文进入选字，行距、行位置应与原正文完全重合，楼层高度不变，退出后也不跳。
- 万一框架没按预期工作：`src/ui/InlineTextSelect.tsx` 里输入框现在是「填满整块」的；正式版是「居中、只有文字高」。回退只需把样式改回居中，并把 `InputBox.fitLines` 的三处调用去掉。

## 2. 首屏两列：左滑折叠

原来只有右滑展开：首屏板块栏 + 帖子列表同屏时，右滑把折起的板块栏展开。这一版加了一个镜像动作——左滑把展开的板块栏收回成图标栏。

- 手势：横向拖动 60pt 以上，或速度 700pt/s 以上才算数；竖直拖动超过 10pt 就交还给滚动。
- 只在一个窗口里既放得下横排又放得下图标栏时生效（宽度 ≥ 900pt）；更窄的窗口本来就只能是图标栏，滑动不会写下一个看不出效果的「折叠」状态。
- 覆盖两处：竖屏 3-2-1 阶梯里的「板块 + 列表」那一层（带原来的右滑），以及横屏/宽窗口里并排的两列（新加的手势，右侧正文栏不受影响）。
