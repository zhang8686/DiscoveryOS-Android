# DiscoveryOSX v1.2.2-1 发布说明（精简版）

发布时间：2026-11-24 ｜ versionCode 71 ｜ `com.Android.DiscoveryOSX`

在 v1.2.2 正式版基础上，修好网页端「引用」显示、补上「回复某一楼」，并优化按钮排版与悬浮按钮手感。选字、手势、图片加载、运行时等 v1.2.2 特性全部保留。

## 核心亮点

1. **引用回复带上正文**：此前从 App 用「引用」发出的回复，网页端只剩「作者 发表于 时间」一行；现在会把被引用楼层的正文一并带上，与网页端引用一致（纯图片楼仍保留一行引用）。
2. **新增「回复某一楼」**：气泡图标是「回复」、空心双下引号是「引用」。点回复后输入框上方出现 `回复 22# mrky` 标签（可清除），发出的回复按论坛格式前置这一行并通知作者；与引用互斥，目标楼层重启后仍保留。
3. **按钮排版更稳、更好看**：引用/回复顺序调整、间距收紧，窄屏也不溢出；引用图标改为与气泡同色的空心双引号，展开菜单底纹同步调淡。
4. **悬浮按钮组可拖动并记住位置**：右下三按钮可作为一组上下拖到任意纵向位置，点按功能不变，位置自动记住，重进帖子回到上次摆放处。
