# DiscoveryOSX v1.2.2-1 更新说明

发布时间：2026-11-24

这是 v1.2.2 正式版之后的修复版（versionCode 71）。只改动回复相关的三件事，v1.2.2 的选字、手势、图片加载、运行时等其余功能一律不变。

## 一、引用回复带上正文

此前用 App 的「引用」回复时，网页端看到的引用框里只剩「作者 发表于 时间」一行，没有被引用的正文。原因是 App 发出的引用只带了署名，没有把楼层正文写进引用里。

现在引用会把被引用楼层的正文以纯文本一并带上，网页端显示与网站自带「引用」一致。纯图片楼没有可读正文，仍保留原来的一行引用（只有作者与时间）。

引用框上方仍只显示作者与时间，正文随回复一起发出；草稿、重进帖子后的还原都照旧。

## 二、新增「回复某一楼」

每楼的操作区现在有两个入口：气泡图标是「回复」，下引号图标是「引用」，两个图标同色、对齐。

- 点「回复」后，输入框上方出现 `回复 22# mrky` 这样的标签（楼层号 + 作者，带 X 可清除）。
- 发出的回复按论坛格式在开头加一行 `回复 22# mrky`，并带上作者通知，与网页端点「回复」一致；不会附带被引用正文。
- 回复与引用互斥：点其中一个会清掉另一个，一条回复只带一种抬头。
- 选中的目标楼层会单独保存，退出帖子再进来仍在，直到发出或手动清除。

## 三、图标微调

引用的下引号图标改为与回复气泡同色，并在各自的按钮内居中，两个图标并排看起来更整齐。纯视觉改动，不影响任何行为。

## 验证

`nsh check` 通过；`nsh test` 162/162 全通过。运行时沿用 nsh nightly `589a60f` 自编译版本，与 v1.2.2 正式版逐字节一致；签名与 v1.2.2 为同一证书，可直接覆盖升级。
