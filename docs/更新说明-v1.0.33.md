# v1.0.33 更新说明

从 v1.0.29 到 v1.0.33，主要是把客户端从「平板好用」打磨成「手机也好用」：修掉了几个影响使用的硬伤（视频楼层空白、键盘不回位、转屏不彻底），并补上了手机端需要的能力。

APK：仓库根目录 `DiscoveryOS-AndroidPad-V1.0.33.apk`（19.8 MB，Android 10 及以上，arm64）。

## 新增特性

1. **板块栏可折叠**：竖屏点标题行右侧图标即可收成只留图标的窄栏，未读数以小徽标挂在图标右上角。
2. **板块计数启动即刷新**：先显示本地缓存，最新未读数回来直接替换，切回板块栏也会自动更新。
3. **图片查看器重做**：全屏黑底、双指缩放 1–4 倍、下滑关闭，底部左右各一枚磨砂「关闭」「保存」按钮。
4. **抖音视频可以内嵌播放**：改走抖音分享页，视频直接在楼层里播放，不再跳转抖音 App。
5. **B 站番剧链接也能播**：`b23.tv/ep…` 自动解析为番剧剧集，用官方播放器加载。
6. **视频默认静音、滑动即暂停**：右上角黑白扬声器可随时开声，滑离播放器立即暂停且不自动续播。
7. **正文标题栏下滑自动隐藏**：正文占满整屏阅读，回到顶部自动滑回；长标题最多两行、左对齐。
8. **新增设置面板**：板块、列表、正文三级字号与行距，深浅色与字体都可调，并记住选择。
9. **头像兜底**：没有头像的用户统一显示应用图标，大小与真人头像一致；列表头像放大到 32。
10. **启动不再等登录**：开着应用即可看到界面与上次账户，会话在后台校验。
11. **列表加载更顺**：单页 50 条、手指停下时静默预取下一页，不再出现转圈等待。
12. **旋转自适应**：横屏三栏、竖屏两栏，转屏即时重排。

## 修复的问题

1. 修复带视频的楼层整屏空白——正文图片按原图尺寸排版，把播放器顶出了屏幕。
2. 修复抖音视频点开一片空白——抖音信息流页拒绝 WebView，改走分享页。
3. 修复 B 站番剧链接被当成普通网页打开、跳到外部 App。
4. 修复手机键盘收起后回复栏悬在屏幕中间不回位。
5. 修复正文标题压住左上角返回按钮。
6. 修复转屏后布局不跟随（横竖屏切换不彻底）。
7. 修复无头像用户的图标与真人头像大小不一致。
8. 修复登录框用户名、密码看不见输入框。
9. 修复板块名尾部混入数字（如「23545」）与整串方块乱码。
10. 修复板块刷新后计数被清零。

## 升级

覆盖安装即可，登录状态与设置会在首次启动后自动恢复；旧版本无需先卸载。
