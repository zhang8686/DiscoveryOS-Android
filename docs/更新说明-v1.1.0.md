# v1.1.0 更新说明

应用更名为 **DiscoveryOSX**，包名变为 `com.Android.DiscoveryOSX`，与旧版 `com.Android.DiscoveryOS` 是两个独立应用，可以并存。
这一版起**同一个安装包适配手机和平板**：界面按窗口宽度自动在单栏、双栏、三栏之间切换。

APK：[Releases · v1.1.0](https://github.com/zhang8686/DiscoveryOS-Android/releases/tag/v1.1.0)
（`DiscoveryOSX-V1.1.0-release.apk`，约 19.9 MB，Android 8.0 及以上，arm64-v8a）

## 兼容性

| 项目 | 支持情况 |
| --- | --- |
| 设备 | 手机、平板通用（含折叠屏、横竖屏切换） |
| 系统 | Android 8.0（API 26）及以上 |
| CPU | arm64-v8a |
| 16 KB 页设备 | APK 与原生库均已按 16 KB 页对齐 |
| 权限 | 仅 `INTERNET` |

## 本版变化

**界面与外观**

- 手机与平板共用一套代码与安装包，布局随窗口宽度自动切换。
- 新增「温暖米色」暖色主题：米色纸张底、浅一档卡片、棕黑文字，长时间阅读更柔和；与跟随系统 / 浅色 / 深色并列，切换即时生效。
- 版块栏可折叠、可拖动排序。
- 正文楼层间距收紧。
- 账户资料卡显示当前版本号。

**列表**

- 分页加载不跳回首页，滚动位置稳定。
- 支持下拉刷新，不足一屏的短列表同样可用。
- 滚动中到达的新数据等手势停下再插入，惯性滑动不被打断。

**正文与图片**

- 正文图片按屏幕像素宽度请求，全宽显示不发虚。
- 图片查看器支持缩放、左右切换、保存，并可扫描图片中的二维码。
- 正文中的网址（含手打的裸网址）可直接点开。

**账号与提醒**

- 头像按 uid 直连论坛 CDN，并按作者逐行渲染。
- 提醒红点与网页同步：进入提醒列表即标记已读，切回前台立即刷新。

**外链与媒体**

- 不再内嵌第三方播放器，B 站 / 抖音等链接交给对应 App 或浏览器。

**稳定性**

- 所有请求增加超时保护（页面 30 秒、附件 90 秒、上传 180 秒），失败自动重试一次。

## 安装

1. 下载 `DiscoveryOSX-V1.1.0-release.apk`，手机与平板同一个文件。
2. 首次安装需允许「安装未知应用」。
3. 与旧版包名不同，可并存；新版首次打开需重新登录。
4. 后续升级请使用同一签名，方可覆盖安装。
