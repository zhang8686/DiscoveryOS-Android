# DiscoveryOSX v1.1.9 更新说明

发布时间：2026-11-23

这一版把「选字」彻底换成系统自带的那一套，复制即收工。

## 一、复制后自动恢复正文

选字界面不再用原生输入框，也不再有任何应用自制的按钮。它就是你熟悉的那套系统文本选区：

- 长按正文 → 再长按选中一个词 → 拖两端手柄逐字增减。
- 浮条上的「复制」点下去，文字进剪贴板，**选区和浮条一起收起，正文立刻恢复**。
- 不用双击，不用点空白处，也不用去找「完成」或「复制」按钮。

实现上利用了一点：系统在复制结束后会清空选区，这个"选区变空"会被应用收到，于是正文就在那一刻回来。也就是说，是系统自己告诉我们"复制完了"。

## 二、手柄与选中底纹改为系统蓝

选中文字的高亮底纹、以及两端手柄的颜色，都改成 Android 系统选区的蓝色（`#4285F4`），与系统里其他应用选字时的观感一致。

## 三、顺带解决的问题

- **去掉自建的「复制」按钮**，也去掉了用原生输入框承载选字的整套做法；选字区域的排版因此变简单，不再需要为对齐做特殊处理。
- **选字后整页点不动**：上一版（v1.1.8）换掉了双击手势但问题未根治，这一版连同承载它的手势路径一起替换，正文恢复后页面点击正常。

## 四、保持不变的

- 长按正文进入选字，点正文以外的地方或按返回键都能退出。
- 附件图片在正文内显示、文件类附件按真实文件名下载、图片查看器的保存与分享，与前几版一致。

## 安装说明

- 包名 `com.Android.DiscoveryOSX`，版本 1.1.9（versionCode 58）。
- 签名与 v1.1.6 / v1.1.7 / v1.1.8 相同，**可直接覆盖升级**。
- v1.1.0 用的是另一份证书，需先卸载再安装。
